title: "Panabit 上禁 IP"
date: 2026-11-06

家里在用 Panabit 流控标准版（新版 UI），管理地址是 https://10.0.0.9，账号 snjesus。有次想禁掉一个地址，管理页里现成的示范规则看着很像答案，但用错地方会白忙一场。

关键区别是：DNS 管控只能断 DNS 查询。DNS 管控 → 策略管理页已有现成规则示范：402（目标地址=恶意地址、动作丢弃）、403（源地址=恶意地址、动作丢弃），用地址对象 + 丢弃动作拦流量。照着 402/403 在 DNS 管控里仿一条，只能拦住域名解析，对方直接连 IP 地址照样通。想断掉某个地址的全部流量，得走流量控制：建一条策略组匹配那个地址，绑到一个上下行带宽都是 0 的数据通道上，等于阻断。先在「数据通道」新建一条上下行填 0、命名"阻断"，再在策略组里绑它。

策略组和地址对象、丢弃动作的用法，管理页里已有现成规则可以照着抄，照猫画虎不难。真正没验证过的是 0 带宽通道能不能保存下来——如果保存时报错，就把报错截图回来再看。还有一点：这条规则只对那一个地址生效，别误伤正常流量。

现状：方法已定，0 带宽通道能否保存、实测效果如何，等反馈。
